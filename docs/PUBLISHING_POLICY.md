# 公開ポリシー（著作権・プライバシー）

このリポジトリは **公開** されています。コミット前にこのチェックリストを確認してください。
※ 法的助言ではなく、自分用の安全側の運用ルールです。

## 1. 著作権・商標（Re-Logic の権利を侵害しない）

### コミットしてはいけないもの
- ゲーム本体のファイル（`Terraria.exe`、DLL、`Content/` フォルダ一式）
- ゲームから抽出した画像・スプライト・音声・BGM（`.xnb` / `.xwb` など、変換後の `.png` / `.wav` も含む）
- ゲームを逆コンパイルしたソースコード（一部の貼り付けも避ける）
- Wiki の本文・画像のコピー
  - 公式 Wiki（terraria.wiki.gg）の文章は CC BY-SA ライセンスで、利用には帰属表示と同一ライセンスでの公開が必要。
    手軽に混ぜ込むと条件を満たせなくなるので、原則としてリポジトリには入れない。

### 代わりにどうするか
- **アセットや大量データが必要な場合は「実行時に、利用者自身のゲームインストールから読み込む」設計**にする。
  リポジトリにはそれを読み込むコードだけを置く。
- 画像が必要なら自作のものか、ライセンスが明確な素材を使う（出典を `CREDITS.md` に記載）。
- アイテムの数値など少量の事実データは自分で入力したものに留める。Wiki やゲームから一括コピーした
  データベースは入れない。

### 名前・表記
- ツール名やアイコンを公式のものと誤認される形にしない（公式ロゴは使わない）。
- README に非公式である旨の注意書きを入れる。

## 2. プライバシー（自分の個人情報を出さない）

### コミットしてはいけないもの
- セーブデータ（`.plr` / `.wld` とそのバックアップ）— キャラ名・ワールド名などが含まれる
- 本名・Steam ID・Steam のユーザー名が写ったスクリーンショット
- マルチプレイのサーバーアドレス・パスワード
- 自分の PC の絶対パス（例: `C:\Users\<ユーザー名>\Documents\...`）
  - パスは環境変数（`%USERPROFILE%` / `$HOME`）や設定ファイルから組み立てる
- API キーなどの秘密情報（`.env` に置き、`.env.example` だけをコミット）

### 個人設定の置き場所
- 個人設定は `*.local.json` や `config.local.*`、`local/` に置く（`.gitignore` 済み）。
- 公開用にはダミー値のサンプル（例: `config.example.json`）だけを置く。

### Git の設定
- コミットのメールアドレスは GitHub の noreply アドレスにする
  （GitHub → Settings → Emails → "Keep my email addresses private"）。
  ```
  git config user.email "<ID>+<ユーザー名>@users.noreply.github.com"
  ```
- 一度プッシュした履歴は、ファイルを削除しても過去のコミットに残る。
  誤ってプッシュした場合はファイルを消すだけでは不十分（履歴の書き換えや、秘密情報なら無効化が必要）。
