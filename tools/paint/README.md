# ペンキドット絵

16色のペンキでドット絵の設計図を描き、ゲーム内で白いブロックにペンキを塗って再現するためのツール。

## できること
- **描く**: ペン / 消しゴム / 塗りつぶし / スポイト / 直線 / 四角 / 円 / 移動、**左右対称**モード
- **建築ナビ**: 1行ずつ「左から 赤×3 → 黒×2 …」と列番号つきで表示。行ごとに完了チェック（作品ごとに保存）。
  下から／上からの順番を切り替え可。キャンバスをタップ（なぞる）で行を選択
- **作品**: 複数の作品を保存・切り替え・名前変更・複製・削除。全作品を JSON ファイルにバックアップ／復元
- **画像の取り込み**: ネットや自作のドット絵画像から、マス目を自動で見つけて16色に置きかえ（[仕組み](docs/import.md)）
- **表示**: 拡大縮小（ホイール・2本指・ボタン）、グリッド、10マスごとの太線、座標表示
- **その他**: 元に戻す（80手）、色ごとのマス数（＝必要なペンキ数）、PNG 書き出し、色の調整
- **オフライン**: ホーム画面に追加でき、一度開けば通信なしでも使える

## ショートカット
| キー | 動作 |
| --- | --- |
| B / E / F / I / H | ペン / 消しゴム / 塗りつぶし / スポイト / 移動 |
| L / R / O | 直線 / 四角 / 円 |
| M / N / G | 左右対称 / 建築ナビ / グリッド |
| + / - | 拡大 / 縮小 |
| Space + ドラッグ、中・右ドラッグ | 移動 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| 建築ナビ中: ↑↓ / Enter | 行の移動 / 完了 |
| Ctrl+V、ドラッグ＆ドロップ | 画像の取り込み |

## 保存について
作品は端末のブラウザ（localStorage）にのみ保存し、外部には送らない。キー:
`teratool1.paint.settings`（設定）/ `teratool1.paint.works`（一覧）/ `teratool1.paint.work.<id>`（中身）。
旧形式 `teratool1.paint.v1` は初回起動時に「作品 1」として自動で引き継ぐ。

## ファイル構成
| 場所 | 役割 |
| --- | --- |
| `index.html`, `css/` | 画面とスタイル（画面全体 / シート / ナビ / 作品一覧 / 取り込み） |
| `js/main.js` | 起動・ボタンの配線 |
| `js/state.js`, `js/util.js` | 定数・状態 / 汎用関数 |
| `js/render.js`, `js/view.js` | キャンバス描画 / 拡大縮小・表示位置 |
| `js/draw.js`, `js/shapes.js`, `js/input.js` | 描画処理（対称含む） / 図形 / ポインタ・キー操作 |
| `js/palette.js`, `js/history.js` | 道具・パレット・集計 / 元に戻す |
| `js/sheet.js`, `js/menu.js` | シートの開閉 / メニュー・PNG 書き出し |
| `js/navi/` | 建築ナビ |
| `js/works/` | 作品の保存・一覧・バックアップ |
| `js/import/` | 画像の取り込み（[docs/import.md](docs/import.md)） |

## 色について
ペンキの色はゲームから抽出したものではなく、見た目を手で合わせた近似値。
