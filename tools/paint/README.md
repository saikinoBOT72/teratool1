# ペンキドット絵

ペンキでドット絵の設計図を描き、ゲーム内でジェムスパークの壁にペンキを塗って再現するためのツール。

## できること
- **色**: ペンキ29色＋「透過」（何も置かない。消しゴムの代わり）。色はジェムスパークの壁に塗ったときの実測値。
  マスごとに「ペンキ × 壁の種類（ダイヤ以外 / ダイヤ）× 光（オフ / オン）」を持つので、1つの作品に混ぜられる。
  ペンキ一覧で「塗る壁」を選んでから塗る（スポイトで取るとペンキと壁の両方が選ばれる）。
  **ゲーム画面 / 全体マップ**は表示の切り替え（描いた中身は変わらない）
- **画面**: 普段は下に1行のバー（道具・ペンキ・左右対称・建築ナビ）だけを出してキャンバスを広く使う。
  道具・ペンキは押したときだけ一覧が開き、選ぶと閉じる
- **描く**: ペン / 塗りつぶし / スポイト / 直線 / 四角 / 円 / 移動、**左右対称**モード
- **建築ナビ**: 1行ずつ「左から 赤×3 → 黒×2 …」と列番号つきで表示（ダイヤ・光オンのマスには印）。下から／上からを切り替え可。
  キャンバスをタップ（なぞる）で行を選択
- **作品**: 複数の作品を保存・切り替え・名前変更・複製・削除。全作品を JSON ファイルにバックアップ／復元
- **画像の取り込み**: ネットや自作のドット絵画像から、マス目を自動で見つけてペンキに置きかえ（[仕組み](docs/import.md)）。
  ファイル・写真の選択のほか、コピーした画像を「貼り付け」ボタン / Ctrl+V / ドラッグで取り込める。
  明るさ・コントラスト・鮮やかさ・色相、使うペンキの選択、色を透明に、ゴミ取り、ふち取り、反転・回転ができる
- **その他**: 拡大縮小、グリッド、元に戻す（80手）、ペンキごとのマス数、PNG 書き出し、オフライン対応
- **スマホ**: ダブルタップ拡大・ページのピンチ拡大・長押しの選択やメニューを止めている（`assets/mobile.*`）

## ショートカット
| キー | 動作 |
| --- | --- |
| B / F / I / H | ペン / 塗りつぶし / スポイト / 移動 |
| E / V | 透過を選ぶ / ゲーム画面⇔全体マップ |
| L / R / O | 直線 / 四角 / 円 |
| M / N / G | 左右対称 / 建築ナビ / グリッド |
| + / - | 拡大 / 縮小 |
| Space + ドラッグ、中・右ドラッグ | 移動 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| 建築ナビ中: ↑↓ | 行の移動 |
| Ctrl+V、ドラッグ＆ドロップ | 画像の取り込み |

## 保存について
作品は端末のブラウザ（localStorage）にのみ保存し、外部には送らない。キー:
`teratool1.paint.settings`（設定）/ `teratool1.paint.works`（一覧）/ `teratool1.paint.work.<id>`（中身）。
マスの値は `壁 × 29 + ペンキ番号`（0 = 透過）。旧形式（1枚だけの `teratool1.paint.v1`、旧16色、壁が全体で1つだった版）は
起動時に一度だけ今の形式に置きかえて保存し直す（壁はそのとき選んでいたもの）。

## 色について
ペンキの色は、作者が自分で撮ったスクリーンショットの各マス中央の値（ゲームのファイルから取り出したものではない）。
JPEG のため少しずれることがある。全体マップでは普通と濃いペンキが同じ色になる。
