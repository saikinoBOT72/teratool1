# ペンキドット絵

16色のペンキでドット絵の設計図を描くツール。ゲーム内で白いブロックにペンキを塗って再現する想定。

## できること
- **描く**: ペン / 消しゴム / 塗りつぶし（4方向） / スポイト / 移動
- **表示**: 拡大縮小（ホイール・2本指・ボタン）、グリッド、10マスごとの太線、カーソル位置の座標
- **キャンバス**: 1〜200マス（プリセット 16〜96）、全消去
- **元に戻す / やり直し**: 80手まで（再読み込みで消える）
- **集計**: 色ごとのマス数（＝必要なペンキの数）と合計
- **画像の取り込み**: 16色に減色（Lab 色差、ディザあり/なし、長辺のマス数を指定）
- **書き出し**: PNG（1倍 / 8倍 / 16倍）
- **色の調整**: 16色それぞれをカラーピッカーで変更（ゲーム画面に合わせる用）
- **保存**: 絵と設定をこの端末のブラウザに自動保存（1枚のみ）

## ショートカット
| キー | 動作 |
| --- | --- |
| B / E / F / I / H | ペン / 消しゴム / 塗りつぶし / スポイト / 移動 |
| G | グリッド切り替え |
| + / - | 拡大 / 縮小 |
| Space + ドラッグ、中・右ドラッグ | 移動 |
| Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） | 元に戻す / やり直し |

## ファイル構成
| ファイル | 役割 |
| --- | --- |
| `index.html` / `paint.css` | 画面とスタイル |
| `js/main.js` | 起動・ボタンの配線 |
| `js/state.js` / `js/util.js` | 定数・状態 / 汎用関数 |
| `js/render.js` / `js/view.js` | キャンバス描画 / 拡大縮小・表示位置 |
| `js/draw.js` / `js/input.js` | 描画処理 / ポインタ・キー操作 |
| `js/palette.js` | 道具・パレット・集計表示 |
| `js/history.js` / `js/storage.js` | 元に戻す / 自動保存 |
| `js/menu.js` / `js/importer.js` | メニュー・PNG書き出し / 画像取り込み |

## 色について
ペンキの色はゲームから抽出したものではなく、見た目を手で合わせた近似値。
