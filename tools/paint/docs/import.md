# 画像の取り込みの仕組み

だいたいで切り抜いた・解像度がバラバラなドット絵の画像から、元のドット（1マス）を取り出して16色に置きかえる。
画像は端末内だけで処理し、送信しない。

## 流れ
1. **読み込み**（`import/index.js`, `import/sources.js`）: ファイル・写真の選択、コピーした画像の貼り付け
   （ボタンはクリップボードから読む / Ctrl+V）、ドラッグ＆ドロップ。長辺 2048px を超える画像は縮小。
   ページからドラッグした画像が URL しか渡されない場合は、外部と通信しないよう取りに行かず、コピー＆貼り付けを案内する
2. **背景を見つける**（`import/pixel-bg.js`）: 外周でよく出る色（2色まで。市松模様の透過表示にも対応）で、
   外周からつながっているピクセルを背景とみなす。以降のマス目探しは背景以外だけで行う
3. **拡大されていない画像か**（`import/unscaled.js`）: 「1ピクセル幅の飛び出し」が多ければ 1ピクセル = 1マス
4. **マスの大きさ**（`import/grid.js`）
   - 明るさの「傾きの変化」（2階差分）を列・行ごとに足したグラフを作る。くっきりした拡大でも、
     ぼかした拡大（マスの中心で折れ曲がる）でもマスの大きさの周期が出る
   - 1ピクセルの寄与に上限を付け、強い境目1本に引きずられないようにする
   - JPEG の 8px ブロックの段差は補間して消す（色味は 16px ブロックなので明るさだけを使う）
   - 自己相関をとり、周期 p, 2p, 3p … の平均点が最高点の 6 割以上になる最小の p を選ぶ（倍の周期の取り違え防止）
   - 端までのずれが 1/4 ピクセル以内になる細かさで p を詰める
   - 縦横の片方がもう片方のほぼ整数倍なら、小さい方に合わせる
5. **ずれ（境目の位置）**: マスの内側の色のばらつきが一番小さくなる位置
6. **マスの色**（`import/cells.js`）: 各マスの中心付近（大きいマスほど狭く）の色の中央値
7. **ペンキに置きかえ**（`import/convert.js`, `import/background.js`）: マス単位で背景を透明に → 余白を詰める →
   明るさ・コントラスト・鮮やかさ・色相を調整 → 「使うペンキ」の中から Lab 色空間で一番近いものに
   （色は今の見え方＝ゲーム画面/全体マップ・壁・光のもの）
8. **仕上げ**（`import/postprocess.js`）: 結果をタップして選んだ色を透明に → 1マスのゴミ取り → ふち取り → 反転・回転
   （操作は `import/adjust-ui.js`）

## 確かさの表示
周期の強さ（自己相関の比）。くっきりした拡大で 0.25 以上＝高、強くぼやけた画像で 0.1 前後＝中、
ドット絵でない画像は 0.1 未満＝低。

## 苦手なもの
- 小さい絵をぼかして大きく拡大し、さらに JPEG にしたもの（隣の色が混ざり、近い色のペンキと取り違えることがある）
- JPEG は細かい部分の色が薄くなるため、濃いペンキが普通のペンキになりやすい →「使うペンキを選ぶ」で絞る
- 絵の白と背景の白がつながっている場合（背景として消える）→「背景を自動で透明にする」を外す
- 自動で合わないときは「1マスの大きさ」を手で入れる（近くを ±1% だけ探して合わせる）
